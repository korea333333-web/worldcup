# 2026 월드컵 팀 인텔리전스

2026 북중미 월드컵 참가팀을 조별 현황, 스타 플레이어, 유튜브 영상, 매치업 예측, 32강 시나리오로 탐색하는 정적 웹앱 프로토타입입니다.

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 실행됩니다. 별도 설치나 서버가 필요 없습니다.

## 첫 버전 범위

- 12개 조 대시보드
- 팀 상세 모달
- 스타 플레이어 카드
- 관련 유튜브 검색/영상 링크
- 샘플 승률이 명확히 표시되는 매치업 분석
- 각 조 1, 2위와 3위 상위 8팀을 보여주는 32강 시나리오

승률과 일부 조 편성은 프로토타입 시나리오입니다. 실제 데이터가 확인되면 `data.js`에서 교체할 수 있습니다.
